# Angelika

I build systems that run themselves, with a human at the gate.

28 agent systems built, 26 in production. Every one has a deterministic gate a model cannot talk past, and a named human who approves what crosses it. Claude API, MCP, LangGraph, n8n, Next.js, Python. Manila.

## Three to open first

**[warrant](https://github.com/mariaangelikabuilds/warrant)** · An MCP server an agent cannot talk past. Class 2 actions raise a protocol-level elicitation instead of running, every decision is sealed into a hash chain, and a two-arm eval measures what the gate costs.

**[meridian-ops](https://github.com/mariaangelikabuilds/meridian-ops)** · A fictional MSP that runs itself. Claude agent fleet, deterministic gates, live monitors on real infrastructure, approval surfaces on the web and monday.com. Runs 24/7 on fly.io.

**[alaga-guest-agent](https://github.com/mariaangelikabuilds/alaga-guest-agent)** · Guest-facing hospitality agent on the Claude SDK with stay-long memory and an escalation guardrail that runs before and after the model.
