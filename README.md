# Maria Angelika Agutaya

**AI Automation Engineer | AI Agents, n8n & API Integrations**

I build AI agents and workflow automations that connect business tools, reduce manual handoffs, and keep important decisions with people.

My work covers workflow design, backend APIs, integrations, testing, and the interfaces teams use to review and approve actions. My product design and frontend background helps me build both the automation and the screens around it.

## What I build

- **Workflow automation and API integrations:** intake, routing, notifications, approvals, reporting, and document handling, with custom Python or TypeScript where native connectors are not enough.
- **AI agents and LLM integrations:** Claude and OpenAI connected to tools, with explicit permissions, checkpoints, and escalation to a person.
- **Internal tools and dashboards:** review queues, approval screens, and interfaces for managing automated work.
- **Evaluation and reliability:** output validation, error handling, audit records, and tests for whether an agent follows its rules.

## Selected work

**[Meridian Ops](https://github.com/mariaangelikabuilds/meridian-ops)** — An operations automation portfolio project for a fictional managed service provider. Combines incident triage, live infrastructure monitors, and human approval surfaces on the web and monday.com.

**[Alagà guest agent](https://github.com/mariaangelikabuilds/alaga-guest-agent)** — A hospitality AI agent built with the Claude SDK, stay-long memory, and escalation checks that run before and after the model.

**[Phishing simulation production line](https://github.com/mariaangelikabuilds/phishing-sim-line)** — A sanitized workflow rebuild showing how AI-assisted content generation and deterministic packaging fit into cybersecurity training production.

**[Warrant](https://github.com/mariaangelikabuilds/warrant)** — An MCP server that requires human approval for governed actions, records decisions in a hash chain, and includes an evaluation of the approval gate.
